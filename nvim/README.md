# 💤 LazyVim

A starter template for [LazyVim](https://github.com/LazyVim/LazyVim).
Refer to the [documentation](https://lazyvim.github.io/installation) to get started.

Required Dependencies
● Neovim (v0.10+ recommended)
● Git
● Curl
● Unzip
● Ripgrep
● Fd (fd-find)
● Python 3 (python3, python3-pip)
● Node.js & npm
● Clang (for C/C++ development)
● LazyGit (optional, for Git integration)
● Tmux (optional, for terminal multiplexing)

Mason Dependencies (Auto-Installed by Neovim)

● Stylua
● ShellCheck
● Shfmt
● Flake8
● Black
● Clang-Format
● Clangd
● Lua Language Server
● Pyright
